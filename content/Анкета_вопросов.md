АНКЕТА ДЛЯ УТОЧНЕНИЯ ТРЕБОВАНИЙ
к проекту «AI-помощник для бизнеса»

1. Общие сведения
   1.1 Ответственное лицо:Коновалов Иван Андреевич - руководитель проекта, принимает решения по функционалу, срокам и бюджету.
   1.2 Цель MVP:Снижение нагрузки на службу поддержки, повышение конверсии обращений в заказы.Метрики: доля автоматизированных обращений ≥30%, рост скорости ответов ≥20%, рост.
   1.3 Языки и регионы:Русский язык, Россия и СНГ.
   1.4 Ограничения:Срок MVP - 3 месяца, бюджет - 5 млн. руб, размещение в облаке.

2. Объём проекта
   2.1 Входит в MVP:
   Чат-бот на сайте
   Панель загрузки контента и обработка через RAG
   Передача диалога менеджеру
   Оплата подписки
   Сервис поддержки через тг
   Исключается: аналитика, мультиязычность, интеграция с тг и прочими системами для передачи запросов менеджерам.
   2.2 Каналы:Сайт, Telegram.
   2.3 Интеграции:Telegram для системы поддержки + Юmoney для оплаты + любая CRM для уменьшения объема работВ CRM сохраняются чаты пользователей.
   2.4 Ответственный за базу знаний:Коновалов Иван Андреевич.

3. UX и пользовательские сценарии
   3.1 Типы пользователей:Клиент, менеджер (работа с клиентом), администратор (добавление новых менеджеров, загрузка файлов для дообучения.);
   3.2 Инициация диалога:
   На иконке чата должно появиться уведомление о новом сообщении через 5 секунд после захода на страницу
   Сообщение с приветствием и предложением помочь
   3.3 Запрашиваемые данные:Имя, телефон, e-mail (по согласию).
   3.4 Передача диалога менеджеру:Система должна сама передавать диалог менеджеру, когда пользователь нажмет кнопку из списка предложенных сообщений (позвать менеджера)Или же когда система не может ответить на вопрос, так как не располагает этими данными

4. Качество ответов и модель LLM
   4.1 Источники знаний:Свой же сайт для обучения и проверки работы, документы, шаблоны ответов
   4.2 Донастройка модели:На старте - системный промт и контекст RAG.
   Затем донастройка в случае неточной работы
   4.3 Стиль общения:
   Дружелюбный, уважительный.
   4.4 При отсутствии ответа:Фраза по умолчанию и передача менеджеру.

5. Интеграции и данные
   5.1 CRM:Bitrix24, Api
   5.2 Платёжные шлюзы:Юmoney, рубли
   5.3 Аналитика:GA4.
   5.4 Конфиденциальные данные:Контакты и история диалогов, все личные данные пользователей. Шифрование при передаче и хранении.

6. Безопасность и соответствие
   6.1 Стандарты:152-ФЗ, GDPR (при работе с ЕС после MVP).
   6.2 Аудит/пентест:Да.
   6.3 Хранение данных:6 месяцев, на облаке.
   6.4 Ответственность за безопасность:Исполнитель - реализация защиты, Заказчик (Коновалов Иван Андреевич) - управление ключами.

7. Производительность и SLA
   7.1 Нагрузка:До 1000 одновременных пользователей, до 10000 запросов/сек.
   7.2 Время ответа и аптайм:До 15 секунд, ≥99%.
   7.3 SLA-метрики:MTTR ≤ 1 cуток, RTO ≤ 2 суток, RPO ≤ 1 часа.
   7.4 Многорегиональное развёртывание:Не требуется на этапе MVP.

8. План-график и приёмка
   8.1 Контрольные точки:Обработка базы знаний и релевантные ответы на вопросы, чат-виджет, система для подключения менеджеров и чаты с ними.
   8.2 Приёмка:UAT, тесты c 95% успешных сценариев касательно работы чат-бота.
   8.3 Документация:Инструкция администратора, документация api для дальнейшего расширения, инструкция по подключению чат-бота на сайт для клиентов.

9. Поддержка и развитие
   9.1 Поддержка после релиза:
   24/7 первые две недели затем с 8 до 10, Telegram/Email.
   9.2 Обновления:Ежемесячно и реже после реализации полного продукта.
   9.3 Обучение персонала:Да, онлайн-инструкция.
   9.4 Изменения после релиза:Через систему тикетов, по согласованию.
